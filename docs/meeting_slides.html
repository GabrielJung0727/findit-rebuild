SECTION 4 · ACTION ITEMS

교수님 Step 1 — GCP 가입

소요: 약 15분 · 비용: $0 (카드 등록만)
1
https://console.cloud.google.com
  • Google 계정 로그인 (평소 쓰시는 Gmail)
  • "무료로 시작하기" 클릭 → 국가: 대한민국 → 카드 등록
    → $300 크레딧 + 90일 자동 부여 / 평가판 종료 시 자동결제 X
  • 예산 알림 설정 (필수, 5분)
    결제 → 예산 및 알림 → 새 예산: findit-budget / $1 / 50·90·100% 알림
  • 저희에게 결제 권한 부여
    결제 → 결제 계정 관리 → 권한 → 추가 → 우리 Gmail / 역할: "결제 계정 사용자"
⚠️ 권한 주의 — "관리자" 가 아닌 "사용자"

"결제 계정 사용자"(Billing Account User) 권한만 부여 → 카드 정보 / CVC / 명세서 접근 불가. 프로젝트를 결제 계정에 연결하는 것만 가능. 교수님 카드는 안전합니다.

SECTION 6 · Q&A

예상 질문 — 미리 준비

Q1. 카드 정보 누가 보나요?

교수님만 보십니다. 우리에게 부여되는 권한은 *프로젝트 연결*만 가능, 카드/명세서 접근 불가.

Q2. 무료 초과 시 어떻게 되나요?

자동 차단 X, 알림만. 그래서 (1) 월 예산 $1 알림 + (2) 매주 카톡 보고. 초과 우려 시 즉시 일시중단 가능.

Q3. 사용자 늘면 비용은?

DAU 100 = $0 / 1,000 = $9~12 / 5,000 = $35~55 / 10,000+ = $200~ (이때부터 매출이 비용 상회).

Q4. 라이선스는?

원본 APK 운영 종료 → 학술 목적 디컴파일. 신규 서버 코드는 신규 작성. 출시 시 LICENSE 파일 명시.

Q5. Play 거절되면?

사유 보통 (1) 개인정보처리방침 (2) 권한 과다 (3) 부정 콘텐츠. 사전 체크리스트 준비 + 1~2일 내 수정 가능.

Q6. 졸업 후 운영은?

코드 + 운영 가이드 GitHub Wiki / docs/ 정리. 후배 또는 외주 인수인계 가능 수준.
