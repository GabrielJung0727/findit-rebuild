HOW TO PLAY

플레이 방법 — 4단계

간단합니다. 좌우 두 그림을 비교해서 다른 부분을 터치하세요.

📲

설치 + 입장

APK 다운로드 + 설치 후 Guest 입장 또는 회원가입. GCP 서버에 즉시 연결.

🎮

매칭 + 배틀룸

친구 초대 또는 랜덤 매칭. 양측 준비 완료 시 자동으로 게임 시작.

🔍

40초 안에 5개 찾기

좌우 두 그림에서 다른 부분 터치. 정답 시 콤보 누적, 오답은 200ms 진동 + 디밍.

🏅

승리 + 보상

승자 = 찾은수 × 50 + 보너스 100 + 콤보 보너스. 코인 / 포인트 획득 → 스킬 학습.

FAQ

자주 묻는 질문

이 게임은 무엇인가요?
FindIt: The Battle 은 2012~2014 년 한국에서 KT olleh / SKT T-Store / Samsung Galaxy / Google Play 4개 스토어에 동시 출시되었던 다른 그림 찾기 1:1 멀티플레이 게임입니다. 원본 서버가 2014년 종료된 후, 학술 목적의 디컴파일 + 신규 GCP 서버 구축으로 재출시 가능 상태로 만든 리빌드 프로젝트입니다.
iOS 버전은 언제 나오나요?
현재 Android 테스트 빌드 우선 진행 중입니다. iOS 버전은 Apple Developer Program 가입 + Flutter 클라이언트 통합 후 추가 예정입니다. 진행 상황은 GitHub 리포에서 확인 가능합니다.
설치하면 안전한가요?
이 APK 는 학술 목적의 테스트 빌드입니다. debug 서명되어 있고 Play Store 정식 출시 전 단계라 "출처를 알 수 없는 앱" 경고가 표시될 수 있습니다. 코드는 GitHub 에 공개되어 있으며 GCP 서버 외 다른 외부 서버와는 통신하지 않습니다.
GCP 운영 비용은 누가 부담하나요?
교육 / 연구 목적의 비영리 프로젝트이며, GCP Always Free 티어 + $300 신규 가입 크레딧 안에서 운영됩니다. DAU 1,000 명 이하 구간에서는 월 $0 ~ $12 수준으로 유지됩니다.
멀티플레이가 안 될 때는?
서버 상태 섹션의 모든 항목이 "정상" 인지 확인하세요. 앱 강제 종료 후 재실행해도 안 되면 GitHub Issue 로 신고 부탁드립니다. 현재 미국 us-central1 리전 사용으로 한국 ↔ 서버 응답 80~120ms 입니다.
소스 코드는 어디서 볼 수 있나요?
전체 소스가 GitHub 에 공개되어 있습니다. 서버 (Node.js) / 클라이언트 (Flutter + Java) / 인프라 (GCP) / 문서 (docs/) 모두 포함.
