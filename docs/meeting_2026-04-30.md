## 2️⃣ GCP 배포 — 어떻게 무료로 운영할 것인가

### 🎯 핵심 전략

> **"Always Free 영구 무료" + "$300 신규 가입 크레딧"** 조합으로 월 $0 운영

### 📐 어떤 리소스를 쓰는가

| 리소스 | 용도 | 무료 한도 |
|---|---|---|
| **Cloud Run** | REST API 서버 | 월 200만 요청 (우리 예상 사용량 50만) |
| **Compute Engine** (e2-micro) | TCP 멀티플레이 소켓 | 월 1대 영구 무료 |
| **Cloud Storage** | 이미지 / 사운드 에셋 | 5 GB |
| **MySQL** (Cloud SQL) | 회원/재화 DB | $9/월 → $300 크레딧 사용 |
| **네트워크** | API 응답 | 외부 송신 1 GB/월 |

### 🌎 리전 — 왜 미국?

- **us-central1 (Iowa)** 가 무료 한도 적용 리전
- **asia-northeast3 (서울)** 은 무료 한도 미적용 (월 $35~)
- 응답 지연: 한국 → 미국 약 80~120ms (게임 플레이에 무리 없음)

```
[한국 사용자]  ──── 80~120ms ──── [GCP 미국 us-central1]
                                          │
                                          ├── REST API (Cloud Run)
                                          ├── 멀티플레이 소켓 (e2-micro VM)
                                          └── 이미지 (Cloud Storage)
```

### 💸 비용 시나리오 3가지

| 시나리오 | 월 비용 | 설명 |
|---|---|---|
| **A. 100% 무료** | **$0** | e2-micro VM + SQLite, MySQL 미사용 |
| **B. 안정 운영** | $9~12 | Cloud SQL 사용, 90일 크레딧으로 무료 |
| **C. 성장 시** | $35~55 | 서울 리전 이전 + Memorystore 등 (DAU 1,000 이상 시) |

> **추천**: 처음 90일은 **B 시나리오** 로 안정성 확보 → 이후 무료 한도 안에서 유지

### 🛡️ 비용 안전장치

1. 결제 콘솔에서 **월 예산 알림 $1** 설정 (50/90/100% 메일 발송)
2. Cloud Run `min-instances=0` (콜드스타트 허용 → 무료 유지)
3. 리소스 자동 스케일 다운 (트래픽 없으면 0원)

> 저희가 직접 **못 하는** 부분만 모았습니다. 순서대로 하시면 됩니다.

### ✅ Step 1. GCP 무료 평가판 가입 (15분)

**작업 위치**: https://console.cloud.google.com

```
[1] Google 계정으로 로그인
[2] "무료로 시작하기" 클릭
[3] 국가: 대한민국 / 카드 등록
   → $300 크레딧 + 90일 자동 부여
   → 평가판 종료 시 자동 결제 X (수동 업그레이드만 가능)
[4] 좌측 메뉴 → 결제 → 예산 및 알림
   → 새 예산 만들기
   → 이름: findit-budget / 금액: $1 USD
   → 알림 50% / 90% / 100% / 이메일 ON
[5] 결제 → 결제 계정 관리 → 권한 → 추가
   → 새 구성원: (저희 Gmail 알려드릴게요)
   → 역할: "결제 계정 사용자" (Billing Account User)
```

> ⚠️ **반드시 "관리자"가 아닌 "사용자" 권한**으로 부여
> → 카드 정보는 못 보고, 프로젝트를 결제 계정에 연결만 가능

### ✅ Step 2. Google Play Console 가입 (20분)

**작업 위치**: https://play.google.com/console

```
[1] Google 계정으로 로그인 + $25 결제
[2] 신원 확인 (1~3일 소요, 학교 사업자등록 가능)
[3] 사용자 및 권한 → 사용자 초대
   → 저희 Gmail 추가
   → 권한: "관리자" 또는 "앱 게시 전용"
```

### ✅ Step 3. Apple Developer Program (선택, iOS 진행 시)

**작업 위치**: https://developer.apple.com/programs/

```
[1] Apple ID 로 로그인
[2] 개인 / 조직 / 기관(면제) 중 선택
   - 기관 면제 신청: 학교 IT팀 통해 신청
   - 일반 가입: $99/년 자동 갱신
[3] 가입 완료 후 People → Invite People
   → 저희 Apple ID 추가 (App Manager 권한)
```

## 6️⃣ 예상 Q&A — 미리 준비

### Q1. 카드 정보 누가 보나요?
**A.** 교수님만 보십니다. 저희에게 부여되는 "결제 계정 사용자" 권한은 *프로젝트를 결제에 연결*하는 것만 가능하고 카드 번호 / CVC / 명세서는 접근 못 합니다.

### Q2. 무료 한도 초과하면 어떻게 되나요?
**A.** GCP는 자동 차단이 없어서 **알림 메일만 옵니다**. 그래서 (1) 월 예산 $1 알림을 설정하고, (2) 우리가 매주 사용량 보고드립니다. 초과 우려 시 즉시 서비스 일시 중단 가능합니다.

### Q3. 사용자가 늘어나면 비용이 얼마나 드나요?
**A.**
- DAU 100명: $0 (무료 한도 안)
- DAU 1,000명: 약 $9~12 (Cloud SQL)
- DAU 5,000명: 약 $35~55 (서울 리전 이전 + 캐시)
- DAU 10,000명+: 약 $200~ (이때부터는 광고/IAP 매출이 비용 상회)

### Q4. 코드 라이선스는 어떻게 되나요?
**A.** 원본 APK 는 2014년 운영 종료된 상태이며, 디컴파일은 학술/연구 목적입니다. 신규 서버 코드는 우리가 새로 작성한 것이라 자유롭게 사용 가능합니다. 정식 출시 시 라이선스 명시(`LICENSE` 파일) 필요합니다.

### Q5. 만약 Google Play 가 거절하면?
**A.** 거절 사유는 보통 (1) 개인정보 처리방침 누락, (2) 권한 과다, (3) 부정 콘텐츠입니다. 우리가 사전 체크리스트로 준비해 두었고, 거절 시 1~2일 내 수정 가능합니다.

### Q6. 학생들이 졸업해도 운영 가능한가요?
**A.** 모든 코드 + 운영 가이드를 GitHub Wiki / docs/ 에 정리해두었습니다. 후배 또는 외주에게 인수인계 가능한 수준입니다.
