📲 설치 방법

3단계로 끝나는 안드로이드 설치 절차. 설치 후 바로 GCP 서버에 연결되어 다른 그림 찾기 배틀을 즐길 수 있습니다.

1

APK 다운로드

위 다운로드 버튼을 누르거나, 안드로이드 폰 브라우저에서 이 페이지에 직접 접속해 다운로드하세요. 다운로드된 파일명: findit-test.apk

2

"출처를 알 수 없는 앱" 허용

안드로이드 설정 → 보안 → "알 수 없는 출처에서 설치 허용" 또는 설치 진행 중 권한 요청 시 허용. 브라우저별로 한 번씩 허용해주시면 됩니다 (Chrome / Samsung Internet 등).

3

설치 + 실행

다운로드 완료 후 알림에서 APK 탭하거나, 파일 관리자로 열어 설치 진행. 첫 실행 시 자동으로 GCP 서버에 연결되며, Guest 입장으로 바로 게임 가능. 또는 회원가입 후 진행상황을 저장할 수 있습니다.

🎮 게임 특징

2013-07 최종 기획서 + 2026 신규 서버 인프라가 결합된 리빌드 빌드입니다.

🔍

다른 그림 찾기

한 이미지에서 7개 차이 중 5개 선착으로 찾기. 40초 제한 시간 안에 상대보다 빨리 발견하는 1:1 배틀.

⚔️

실시간 멀티플레이

친구 초대 + 랜덤 매칭. 콤보 보너스로 +100~700점 추가, 스킬/아이템으로 상대 화면 방해.

🎯

44 스킬 트리

고양이발톱, 강아지발자국, 폭발, 불꽃, 눈꽃, 강력 ×3 — 8 계열 44 스킬을 레벨업으로 학습.

💎

3 재화 시스템

코인 (전투 보상) / 포인트 (스킬) / 보석 (프리미엄). 아이템 9단계 강화, 인벤토리 30칸 확장.

📊

친구 랭킹

Facebook 친구 그룹 랭킹 + 어제 대비 순위 변동 (delta) 표시. 일/주/월 단위 집계.

🛡️

보안 강화

HTTPS 강제 + reCAPTCHA + 영수증 서버 검증. Guest/이메일/Facebook 3개 로그인 방식.
