교수님께서 해주실 일 — 3가지

1
GCP 무료 평가판 가입

Google Cloud Platform

console.cloud.google.com
소요 / 비용
15분 · $0
  1. Google 계정 로그인
  2. "무료로 시작하기" → 카드 등록$300 크레딧 + 90일 자동 부여 / 자동결제 X
  3. 예산 알림 설정결제 → 예산 및 알림 → $1 / 50·90·100% 메일
  4. 우리 Gmail 에 권한 부여결제 → 결제 계정 관리 → 권한 → 추가 / 역할: "결제 계정 사용자"
2
Google Play Console 가입

Android 출시 (필수)

play.google.com/console
소요 / 비용
20분 + 1~3일 심사 · $25 (1회 평생)
  1. Google 계정 로그인
  2. $25 결제 (1회 평생 사용)
  3. 신원 확인학교 사업자등록 가능 / 1~3일 소요
  4. 우리 관리자로 초대사용자 및 권한 → 사용자 초대 / 권한: 관리자
3
Apple Developer Program (선택)

iOS 출시 시

developer.apple.com/programs
소요 / 비용
30분 ~ 2주 · $99/년 또는 $0 (면제)
  1. Apple ID 로그인
  2. 가입 유형 선택개인 / 조직 / 기관(면제)
  3. 학교 면제 신청Apple Developer for Educational Institutions / 학교 IT팀 통해
  4. App Manager 로 우리 초대People → Invite People
⚠️ 권한 주의 — "관리자" 가 아닌 "사용자"
GCP 권한은 반드시 "결제 계정 사용자"(Billing Account User) 부여. → 카드 정보 / CVC / 명세서 접근 불가, 프로젝트 연결만 가능. 카드는 안전합니다.
